# Documentos PMA

Colocar aqui los documentos oficiales del Plan de Manejo Ambiental.

## Carpetas

- `pma_final/`: PDF y DOCX final del PMA.
- `anexos/`: anexos de informes de cumplimiento, organizados por periodo.
- `informes_bianuales/`: informes de cumplimiento historicos por periodo.
- `oficios_presentacion/`: oficios de presentacion por periodo.
