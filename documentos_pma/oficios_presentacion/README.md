# Oficios de presentacion

Carpeta para conservar los oficios con los que se presentaron informes, planes, alcances, respuestas o documentos ambientales ante la autoridad competente.

## Organizacion

Usar una carpeta por periodo de informe:

```text
2015_06_a_2016_05/
2016_06_a_2018_05/
2018_06_a_2020_05/
2020_06_a_2022_05/
2022_06_a_2024_05/
2024_06_a_2026_05/
otros_anios/
```

## Documentos a conservar

- Oficio de presentacion.
- Documento presentado.
- Acuse de recepcion, sello, ticket, correo o constancia.
- Respuesta recibida, cuando exista.

## Nombres sugeridos

```text
2022_06_a_2024_05_oficio_presentacion_informe_bianual.pdf
2022_06_a_2024_05_acuse_recepcion_png.pdf
2022_06_a_2024_05_respuesta_autoridad.pdf
```
