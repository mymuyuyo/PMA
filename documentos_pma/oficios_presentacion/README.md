# Oficios de presentacion

Carpeta para conservar los oficios con los que se presentaron informes de cumplimiento ante la autoridad competente.

## Organizacion

Usar una carpeta por periodo de informe:

```text
2015_06_a_2016_05/
2016_06_a_2018_05/
2018_06_a_2020_05/
2020_06_a_2022_05/
2022_06_a_2024_05/
2024_06_a_2026_05/
2026_06_a_2028_05/
2028_06_a_2030_05/
otros_anios/
```

## Documentos a conservar

- Oficio de presentacion.

Para periodos anteriores a `2026_06_a_2028_05`, los otros documentos historicos se cargan separadamente como informe de cumplimiento y anexos.

## Nombres sugeridos

```text
2022_06_a_2024_05_oficio_presentacion_informe_bianual.pdf
```
