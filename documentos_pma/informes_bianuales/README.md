# Informes periodicos historicos

Carpeta para conservar los informes ambientales presentados por periodo.

La regla historica del expediente es:

- Junio 2015 - mayo 2016: periodo anual excepcional.
- Desde junio 2016: informes cada dos anios, siempre en periodos junio-mayo.

## Organizacion

Cada periodo debe conservar:

- Informe de cumplimiento presentado.
- Oficio de presentacion correspondiente.
- Anexos del periodo.

Para periodos anteriores a `2026_06_a_2028_05`, no se evalua la matriz del plan vigente; solo se conserva el expediente documental historico.

## Periodos base

```text
2015_06_a_2016_05/
2016_06_a_2018_05/
2018_06_a_2020_05/
2020_06_a_2022_05/
2022_06_a_2024_05/
2024_06_a_2026_05/
2026_06_a_2028_05/
2028_06_a_2030_05/
otros_periodos/
```

Los nombres de archivo deben indicar periodo, tipo de documento y contenido.

Ejemplo:

```text
2022_06_a_2024_05_informe_bianual_pma_muyuyo.pdf
```
