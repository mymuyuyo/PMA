Manual para subir informacion

Procedimiento para registrar cumplimiento, cargar evidencias y actualizar el indice documental.

Importante

El sistema no usa API ni escribe directamente en GitHub. Genera un archivo evidence-index.json, que luego debe subirse manualmente al repositorio.

1. Ingresar a subir informacion

  1. Seleccione Subir informacion en el menu principal.
  2. Ingrese las credenciales basicas.
Usuarioadmin
ContrasenaMuyuyo2026#

2. Registrar cumplimiento del plan vigente

Use este formulario para alimentar la matriz desde el periodo 2026-2028 en adelante.

  1. Seleccione la medida del PMA.
  2. Seleccione el estado: Cumple, Pendiente, No aplica o En correccion.
  3. Registre la fecha de revision.
  4. Seleccione el periodo vigente.
  5. Confirme el responsable de revision.
  6. Escriba la ruta del verificador dentro del repositorio.
  7. Escriba el nombre del archivo.
  8. Agregue una observacion breve cuando sea necesario.
  9. Presione Agregar a matriz.

3. Carga asistida de evidencias

Use esta opcion para registrar varios archivos en una misma carpeta del repositorio.

  1. Importe el indice existente si ya tiene un evidence-index.json actualizado.
  2. Seleccione la carpeta destino en GitHub.
  3. Seleccione los archivos a registrar.
  4. Revise la vista previa.
  5. Presione Agregar seleccionados.

4. Editor manual de indice

Use este formulario para documentos puntuales o para el expediente historico anterior a junio 2026.

Para periodos historicos registre solamente:

  • Informe de cumplimiento.
  • Oficio de presentacion.
  • Anexos.

5. Descargar el indice actualizado

  1. Despues de registrar la informacion, presione Descargar indice.
  2. El navegador descargara evidence-index.json.
  3. Suba ese archivo a GitHub en la carpeta data/, reemplazando el anterior.
  4. Suba tambien los documentos o evidencias en sus carpetas correspondientes.
  5. Espere la actualizacion de GitHub Pages y revise el dashboard.
