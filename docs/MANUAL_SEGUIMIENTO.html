Plan de Manejo Ambiental

Manual de seguimiento a planes

Uso del dashboard, filtros, matriz, alertas, evidencias y descarga de documentos.

Regla de vigencia

El seguimiento del plan ambiental vigente se controla desde el periodo Junio 2026 - mayo 2028 en adelante.

Los periodos anteriores a junio 2026 se consultan solo como expediente historico documental.

1. Abrir seguimiento

  1. Abra la pagina del sistema en GitHub Pages.
  2. Seleccione Seguimiento a planes en el menu principal.
  3. Use el boton PMA Vigente cuando necesite abrir el plan ambiental completo en HTML.
  4. Revise los indicadores superiores de cumplimiento general.

2. Usar filtros

  1. Seleccione el Periodo que desea revisar y confirme la etiqueta de periodo activo sobre el tablero.
  2. Filtre por Subplan si necesita revisar una parte especifica del PMA.
  3. Use Estado para ver medidas cumplidas, pendientes, no aplicables o en correccion.
  4. Use Frecuencia para separar obligaciones semestrales, anuales o eventuales.
  5. Use Buscar para ubicar una medida, responsable o verificador.

3. Leer la matriz

Antes de interpretar el cumplimiento, revise el texto de periodo que aparece bajo el titulo de la matriz. Ese texto indica si la matriz corresponde a un periodo vigente o si el periodo seleccionado es historico.

ColumnaUso
SubplanComponente del PMA al que pertenece la medida.
MedidaActividad ambiental que debe cumplirse.
ResponsableArea o persona encargada.
FrecuenciaPeriodicidad de verificacion.
VerificadorDocumento esperado para comprobar cumplimiento.
CriterioCondicion usada para considerar la medida cumplida.
FechaFecha registrada en la revision o evidencia.
EstadoResultado de cumplimiento.
EvidenciasEnlaces a documentos cargados en el repositorio.

4. Revisar alertas

El bloque de alertas muestra medidas pendientes o en correccion. Use estas alertas como lista de trabajo para completar verificadores o cerrar novedades documentales.

5. Descargar documentos del periodo

  1. Seleccione un periodo en el filtro.
  2. Revise el bloque Documentos del periodo.
  3. Presione Descargar documentos.
  4. El sistema descargara solo los documentos relacionados con el periodo filtrado.

6. Periodos historicos

Para periodos anteriores a junio 2026, el sistema no evalua la matriz del plan vigente. En esos periodos se revisan solamente:

  • Informe de cumplimiento.
  • Oficio de presentacion.
  • Anexos.
